06 · Handoff note

Static HTML + CSS

Every section, all copy, the diagram (boxes, borders, CSS triangle arrowheads), the manifest block (pre-highlighted spans), chip rows, footer.
Theme is CSS only until the toggle is touched: tokens on :root, overrides under @media (prefers-color-scheme: dark) and [data-theme="dark"].
Two utility pages are separate static documents at /ext/module/v1 and /schema/, same tokens, no JS.
/install.sh and /install.ps1 are plain files served as text/plain.

Needs JS — nothing else

Theme toggle — cycles auto → light → dark, writes data-theme on <html>, persists in localStorage, inline head script to avoid a flash.
Copy buttons — navigator.clipboard.writeText, label swaps to copied for 1.4s, aria-live="polite".
Install tabs — show/hide panels, arrow-key roving tabindex.
Hero terminal — types the four commands once on load, output lines after each. Skip entirely under prefers-reduced-motion and render the finished transcript. A replay button re-runs it. If you would rather not ship it, the static transcript is the correct fallback.

Responsive + a11y

Breakpoints come from auto-fit minmax(), not media queries. At 375 the diagram's three columns stack and the arrow column rotates to vertical; the manifest sits above its callouts.
Long commands scroll inside their block (overflow-x:auto); body never scrolls sideways.
The accent toggle in the header is a review aid — ship one accent and drop the control.
Diagram carries role="img" and a full aria-label. Focus ring is 2px --acc at 2px offset on every interactive element.
Budget: two font families, no video, no illustration. Ships as static files.
