git-a2a
SchemaSource

Schema 2 specification

A repository declares one component, one responsible external Agent Card, exports, an optional published surface, and direct aliased dependencies with durable adapter selections.

Revision invariant

Manifest metadata, every polyglot binding, submodule-backed build integration, and surface all use the same resolved commit.

Scope

git-a2a applies and inspects dependencies. It does not send A2A messages, run agents, manage tasks, host endpoints, discover transitive owners, or interpret surface data as local authority.

Local ownership discovery

list reports all direct dependencies. whose NAME locates one responsible Agent Card reference and available surface without network access or A2A messaging.
