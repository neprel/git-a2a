What you can do

Wire a git dependency into every package manager you use, at one commit.

git-a2a add ssh://git@github.com/acme/lib-utils.git

Know who owns a dependency and how they want to be asked.

git-a2a who acme-lib-utils --intent change

Put a generated roster of dependencies and owners into AGENTS.md.

git-a2a sync

Send the request where the owner said to.

git-a2a contact acme-lib-utils --intent change

Publish and verify A2A agent cards and an ARD catalog.

git-a2a card export
git-a2a catalog export

See liveness and drift in one line per dependency.

git-a2a status

The manifest

One file at the repository root. What the module is, how to import it, who owns it, and what consumers may do.

a2amodule.yml
schema: 1
module:
  id: acme-lib-utils
  description: Shared string utilities for Acme.
  surface: surface/
  exports:
    - { ecosystem: npm,    name: "@acme/lib-utils" }
    - { ecosystem: pypi,   name: acme_lib_utils }
    - { ecosystem: golang, name: acme.dev/lib-utils }
agents:
  - name: acme-lib-utils
    role: owner
    card: https://agents.acme.example/lib-utils/.well-known/agent-card.json
    contacts:
      - { intents: [question], kind: a2a, url: https://agents.acme.example/lib-utils/ }
      - { intents: [bug],      kind: github-issue, repo: acme/lib-utils }
  - name: acme-pm
    role: spec
    contacts:
      - { intents: [change], kind: github-issue, repo: acme/lib-utils, labels: [change-request] }
policy:
  intents: { change: spec }
  consumers: { may: [read-surface, ask, open-issue], may-not: [commit] }

exports

How to import the module in each ecosystem. Thirteen today: npm, PyPI, Go, Cargo, SwiftPM, Dart, Bundler, Composer, Mix, Cabal/Stack, Zig, Clojure, Nix.

agents + contacts

Which agents own which part of the module, and how each one wants to be contacted per kind of request — a question, a change request, a bug.

policy

What consumers may and may not do, and which agent handles which intent. a2amodule.lock records what was resolved.

Install

One static binary, no runtime. Checksums and SBOM on every release.

curl -fsSL https://git-a2a.com/install.sh | bash
irm https://git-a2a.com/install.ps1 | iex

The second line is for Windows PowerShell.

go install github.com/neprel/git-a2a/cmd/git-a2a@latest
go run github.com/neprel/git-a2a/cmd/git-a2a@latest

One static binary, no runtime.

brew install neprel/tap/git-a2a
scoop install git-a2a

One static binary, no runtime.

npx git-a2a
uvx git-a2a

Runs without installing.

docker run --rm ghcr.io/neprel/git-a2a status

deb, rpm and apk packages are on the releases page. Checksums and SBOM on every release.

How it relates

A2A protocol

git-a2a uses native A2A agent cards and adds one extension. It is not affiliated with the A2A project.

AGENTS.md

git-a2a writes a managed block into it. It does not replace it.

Package managers

git-a2a drives them. It never replaces them.

git-a2a

A2A is a Linux Foundation project; git-a2a is an independent open-source tool.
