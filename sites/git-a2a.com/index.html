Git-native component dependencies

Import the code.
Know who owns it.

git-a2a applies a component through the consumer's platform adapter, records one exact Git commit, exposes the responsible agent's A2A Agent Card, and materializes the component's optional published surface.

git a2a init
git a2a add https://github.com/acme/math.git
git a2a list math
git a2a pull math

One dependency, three aligned results

Code

Native package-manager binding or a safe Git submodule, pinned to one component commit across every language.

Owner

One declared Agent Card: an HTTPS URL or a local copy from the applied commit. Use an external A2A client to talk to the responsible agent; git-a2a does not send messages or run agents.

Surface

Optional tracked API, documentation, examples, or source from that same commit. No declaration means no published surface.

Five commands

initcreate a schema 2 declaration
add SOURCEinstall or resolve code through chosen adapters and save their variants
pull [NAME]update all dependencies, or only NAME, through saved variants; restore missing installed state
remove NAMEremove the dependency and reconcile native locks and installed state
list [NAME] --jsoninspect locally, without network or mutation

Platform adapters

Native Git bindings: npm/Yarn/pnpm/Bun, uv/Poetry/PDM/PEP 621, Go, Cargo, SwiftPM, Pub, Bundler, Composer, Hex, Cabal/Stack, Zig, Clojure and Nix.

CMake, Gradle, MSBuild, Maven and Meson compose with one submodule checkout. On initial add, unsupported native Git sources use the submodule adapter explicitly, with a warning if automatic build integration is unavailable; an unavailable saved tool or variant is an error, never a silent switch.

Run the complete owner loop

The ACME app walkthrough connects a component, discovers its responsible agent, sends a request through A2A, lets the owner change the library, pulls the new commit, and verifies the changed result.

Clone the app and library repositories next to each other. Docker with Compose is required.

git clone https://github.com/neprel/git-a2a-demo-acme-lib.git
git clone https://github.com/neprel/git-a2a-demo-acme-app.git
cd git-a2a-demo-acme-app
./demo/run.sh

# Short npm-only profile
DEMO_PROFILE=npm ./demo/run.sh

Deterministic agents need no LLM API keys. The demo uses real A2A transport, published git-a2a 2.0.0, and temporary local Git remotes. A separate demo client performs A2A communication; git-a2a manages dependency code and metadata. These agents run locally for the demo and are not permanently available public services.

Compare the walkthrough with the verified full-profile transcript.
