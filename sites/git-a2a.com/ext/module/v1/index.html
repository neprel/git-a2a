A2A extension

One extension on native A2A agent cards. It declares which module an agent speaks for, and in what capacity.

URI
https://git-a2a.com/ext/module/v1

Params

module
The module id, as declared in a2amodule.yml.
repository
The git URL the module lives at.
role
What the agent is for this module — for example owner or spec.
scope
The part of the module the agent answers for.
ref
The commit or ref the declaration applies to.

Export and verify cards with git-a2a card export. JSON schema.
